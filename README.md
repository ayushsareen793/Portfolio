## About

A dark-themed, fully responsive single-page portfolio designed in **Figma** and built with **React, Vite, TypeScript, and Tailwind CSS 4**. It showcases my projects, skills, experience, and achievements — with smooth scroll navigation, a copy-to-clipboard email interaction, and a mobile-friendly layout.

**Live site:** [portfolio-ayush-5b8f.vercel.app](https://portfolio-ayush-5b8f.vercel.app)

## Getting Started

```bash
# Clone the repository
git clone https://github.com/ayushsareen793/Portfolio.git
cd Portfolio

# Install dependencies (npm or pnpm — pnpm workspace config included)
npm install

# Start the dev server
npm run dev

# Build for production
npm run build
```
