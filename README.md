# Ayush Sareen — Portfolio

Dark-coffee editorial portfolio built with React and TanStack Start.

## Development

```sh
bun install
bun run dev
```

## Vercel

This repository uses Nitro’s Vercel target and builds Vercel Build Output API files. Keep the existing Vercel project connected to this repository. Build command: `bun run build`.

The old portfolio is preserved on `backup-before-coffee-redesign-2026-11-04`. No credentials are included.
